# Sistema de Correção de Provas com IA - CORRIJA+
  
Este projeto consiste em uma plataforma completa para gestão de professores, provas, questões, critérios de avaliação e processamento automatizado de avaliações respondidas, utilizando técnicas de Processamento de Linguagem Natural (PLN) para auxílio na correção.

# A plataforma permite que professores:
- Cadastrem e gerenciem suas provas e questões.
- Criem critérios de avaliação baseados em palavras-chave ou respostas esperadas.
- Imprimam provas para uso em sala.
- Enviem avaliações respondidas pelos alunos.
- Tenham as respostas processadas automaticamente via PLN.
- Visualizem resultados detalhados por aluno e por questão.
- Verifiquem automaticamente indícios de plágio entre respostas semelhantes.

# Fluxo Geral do Sistema

- O professor cria sua conta e acessa o sistema.
- Cria uma nova prova e adiciona questões discursivas.
- Define critérios de avaliação para cada questão.
- Imprime a prova e aplica aos alunos.
- Envia as respostas (arquivo CSV/XLSX ou imagem da prova).
- O sistema processa cada resposta usando PLN.
- O professor visualiza:
- Correções automáticas.
- Destacamento dos critérios atendidos.
- Notificações de plágio.
- O professor pode revisar, ajustar notas e exportar resultados.
